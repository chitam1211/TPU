Datapath của RV32I Matrix Core v2

Bản v2 bỏ PCPI trong nhánh RV32I pipeline. Custom instruction được bắt ở tầng Execute, làm stall pipeline 5 tầng, rồi đi vào matrix_dispatch và các khối chức năng của matrix_core_v2.

Hình 1. Datapath dispatch/stall trong CPU 5 tầng

IFfetch instruction
→
IDđọc x-reg
→
EXphát hiện opcode matrix
→
matrix_dispatchdecode và điều phối lệnh
matrix_stallgiữ PC, IF/ID, ID/EX
→
EX/MEM bubblekhông cho lệnh matrix đi tiếp
→
matrix_donenhả pipeline

Điểm chính để trình bày: matrix instruction không còn đi qua PCPI. CPU pipeline trực tiếp issue lệnh matrix ở EX, stall cho đến khi khối matrix báo done.

Hình 3. LOAD/STORE datapath

EXmlae/mlbe/mlce
msae/msbe/msce
→
Tile LS FSMrow, beat, address
→
Data memory portrequest/we/mask/address
↔
Matrix regfiletr0..tr3 / acc0..acc3
Load: base = rs1, stride = rs2. FSM đọc từng row trong data memory, nhận word 32-bit, rồi ghi vào matrix regfile theo reg,row,beat.
Store: FSM đọc matrix regfile, phát word 32-bit ra data memory. Với partial row, mem_wstrb chỉ bật các byte hợp lệ.

Hình 4. MAC datapath

tr Apacked INT8
→
MAC DiPpermuted weight + PE array
←
tr BB lưu chuyển vị
→
acc CINT32 result

MAC đọc A/B từ regfile, tải weight B theo từng tile K=4, đưa A đi qua các PE, cộng dồn vào accumulator nội bộ, rồi ghi 16 kết quả INT32 về acc.

Hình 6. MISC datapath

matrix_dispatchstart_misc
→
Matrix regfileread source
→
MISC FSMmove, zero, dup, slide
→
writebackmatrix reg hoặc x-reg

MISC là nhóm thao tác dữ liệu: xóa accumulator, copy register, đưa 1 word sang GPR, đưa GPR vào matrix register, duplicate word, hoặc slide dữ liệu theo row/column.
