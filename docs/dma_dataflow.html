Luồng dữ liệu của Matrix DMA

DMA là khối di chuyển dữ liệu giữa shared RAM và matrix regfile. DMA không tính toán; nó chỉ thực hiện load/store theo lệnh matrix load-store do matrix_pcpi decode.

Tổng quan kết nối

PicoRV32 CPU

Fetch chương trình, phát lệnh matrix qua PCPI.

PCPI
Matrix Core + DMA

Nhận start_mld/start_mst, tạo giao dịch đọc/ghi RAM theo burst.

AXI4-Full subset
Shared RAM

Chứa chương trình, input matrix A/B, output C.

CPU native port

CPU đọc instruction và data qua port riêng.

DMA Engine

Điều khiển địa chỉ, beat, row, strobe.

reg port
Matrix Regfile

Lưu tr0..tr3 và acc0..acc3.

Luồng load: RAM -> Regfile

1. PCPI decode Lệnh như mlae8 tạo pulse start_mld.
2. DMA read address DMA phát AR tới shared RAM theo base address và row stride.
3. RAM read data RAM trả từng beat 32-bit qua channel R.
4. Regfile write DMA ghi reg_id,row,beat,wdata vào matrix regfile.

Luồng store: Regfile -> RAM

1. PCPI decode Lệnh như msce32 tạo pulse start_mst.
2. DMA write address DMA phát AW cho từng row cần store.
3. DMA write data DMA đọc regfile và phát W data, W strobe.
4. Write response RAM trả B response, DMA chuyển row hoặc báo done.

Các state chính của DMA

State Vai trò
ST_IDLE Chờ lệnh load/store mới.
ST_CALC_ROW Tính địa chỉ row hiện tại và số beat cần truyền.
ST_AR_REQ Phát địa chỉ đọc RAM cho load.
ST_R_BURST Nhận dữ liệu RAM và ghi vào regfile.
ST_AW_REQ Phát địa chỉ ghi RAM cho store.
ST_W_BURST Gửi dữ liệu từ regfile ra RAM.
ST_B_WAIT Chờ write response từ RAM.
ST_NEXT_ROW Chuyển sang row kế tiếp hoặc kết thúc DMA.
