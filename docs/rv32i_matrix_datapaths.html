Datapath tích hợp Matrix Core vào RV32I pipeline 5 tầng

Các hình dưới đây mô tả bản RV32I hiện tại sau khi bỏ PCPI khỏi interface CPU. CPU phát lệnh matrix bằng matrix_dispatch, giữ pipeline bằng matrix_stall, và chạy matrix_core_v2 với MAC DiP.

Hình 1. Datapath tổng thể RV32I 5 stage + Matrix Unit

EXALU thường hoặc phát matrix instruction.
MEMLoad/store scalar RV32I.
WBGhi kết quả về GPR.
ID/EX instruction Custom opcode 0101011, rs1, rs2.
→
matrix_dispatch Decode nhóm lệnh config, matmul, misc, ew. Tạo start_*.
→
matrix_core_v2 Điều khiển regfile, EW, MISC và MAC DiP.
Lệnh matrix được phát ở execute stage. Khi matrix core bận, matrix_stall giữ PC, IF/ID và ID/EX; EX/MEM nhận bubble để lệnh matrix không trôi xuống MEM/WB như lệnh thường.

Hình 2. Datapath issue/stall của custom matrix instruction

Không fetch lệnh mới.
IF/ID + ID/EX hold Giữ nguyên instruction matrix đang ở EX.
EX/MEM bubble Đẩy bubble xuống MEM để không ghi nhầm.
Công thức stall hiện tại: matrix_stall = matrix_custom_execute && matrix_supported && !matrix_done. Khi matrix_done lên 1, pipeline đi tiếp.

Bản RV32I v2 hiện chưa claim matrix load/store vì đã bỏ DMA. Dữ liệu test được preload qua host/debug port. Nếu muốn ngang với hệ có Tile Load/Store FSM, cần thêm khối load/store tile ở MEM stage hoặc một FSM riêng.
